# PotholePal

A system for residents to report potholes and for municipal staff and field
teams to triage and fix them. React front end, Express API, SQL Server.

## Layout

```
Pothole-Pal/
├── app/                  The application — everything npm touches lives here
│   ├── src/              React screens, components, icons
│   ├── public/           Logos and PWA icons
│   ├── server/           Express API, database scripts, smoke test, uploads/
│   ├── index.html        Front end entry point
│   ├── package.json      The only real package.json (install happens here)
│   ├── vite.config.js    Dev server + /api and /uploads proxy to port 3001
│   └── eslint.config.js
├── package.json          Convenience only: forwards npm run build/dev/lint into app/
├── group-docs/           The group's deliverable documents
│   ├── builders/         Python scripts that generate the .docx files
│   └── *.docx, *.pdf
├── screenshots/          Walkthrough evidence used in the documents
└── archive/              Superseded material (the day-1 status board)
```

## Running it

Demo mode — one process, one port:

```
npm run build             # from the project root; builds app/dist/
cd app/server && npm start
http://localhost:3001
```

Development mode — hot reload, two terminals:

```
Terminal 1:  cd app/server && npm start     # API on 3001
Terminal 2:  npm run dev                    # front end on 5173
http://localhost:5173
```

Data commands (all from `app/server/`):

```
npm run db:setup     # create the tables, safe to repeat
npm run db:seed      # load accounts, reports, notifications, safe to repeat
npm run db:reset     # wipe everything and seed again
```

Smoke test — with the server running, from the project root:

```
bash app/server/smoke-test.sh
```

## Documents

Every document in `group-docs/` is generated by a script in
`group-docs/builders/`. From the project root:

```
python group-docs/builders/build_tools_docx.py
```
