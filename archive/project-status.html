Where attention is needed now

  • Broken nav link. The Reports tab points at /report, which renders an empty page.
  • Dead buttons throughout. Confirm Location, both Next buttons, Submit Report, every back arrow, the Home search, and the Map filter chips have no handlers.
  • Report flow skips steps. Step 1 navigates to /report4, and step 4 shows hardcoded values (address "123 Maple Ave, Riverton, CA") instead of what the user typed.
  • Lint fails. 2 errors in ReportPotholePage3.jsx: severity and setSeverity declared but unused.
  • Missing assets. profile-photo.png, first-report.png, road-guardian.png, community-hero.png and fast-reporter.png are referenced but not in src/assets, so Profile shows broken images.
  • Images use dev-only paths. Every icon is referenced as a plain "src/assets/..." string, which Vite only serves in dev mode. A production build breaks all of them; they should be imports.
  • No backend, no data. The 128 / 864 / 312 stats are hardcoded, so the accountability numbers the dissertation evaluates do not exist yet.
